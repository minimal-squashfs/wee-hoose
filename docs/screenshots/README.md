# Screenshots

The main README shows these. Take them with the panel in demo mode (no config.jsonc) and with
previews, so nothing from a real home appears in them:

- `day.png`: `?time=13:00`
- `night.png`: `?time=22:10&weather=snowy`
- `birthday.png`: `?celebrate=birthday&time=16:00&weather=sunny`
- `room.png`: `?room=living&date=2026-12-25&time=20:00`

The "Demo mode" label is hidden while a preview is in the address, so the pictures are clean.
A landscape tablet size (about 1000 x 600) works best.
